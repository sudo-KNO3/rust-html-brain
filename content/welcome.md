# Welcome

This is a static knowledge base generated by `kb`, a small Rust tool that
turns Obsidian-style markdown into a browsable HTML site.

## How it works

1. `kb` walks every source path in `config.toml` (your `~/.claude` memory
   directory plus this `content/` folder by default).
2. Each `.md` file becomes one HTML page under `output/notes/<slug>.html`.
3. `[[wikilinks]]` between notes become hyperlinks. Targets that don't
   resolve are styled in red so you can see dangling references.
4. The [graph view](../graph.html) shows the full note graph or — with
   the toggle — just projects coloured by status.

## Adding a note

Drop a new markdown file in this `content/` folder. Use frontmatter like:

```yaml
---
name:        my-new-note
description: one-line summary
metadata:
  type:   project | reference | feedback | user
  status: active | paused | done
---
```

Then re-run `cargo run --release` to rebuild.
